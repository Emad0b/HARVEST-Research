# Publication scope

This repository is a deliberately separate documentation release with a fresh Git history.

## Public material

- Research purpose and high-level system roles.
- Evaluation design and measured quantities.
- Selected aggregate research outcomes and benchmark summaries.
- Limitations, provenance and future research directions.
- Reviewed research-result figures and a high-level Unity validation narrative.

## Withheld material

- Hybrid A* source code, equations, pseudocode, heuristic construction and tuning logic.
- Other project source code, scripts, notebooks, binaries and internal interfaces.
- Unity project assets, scenes, build outputs and local configuration.
- Exact private experiment configurations, raw logs and unpublished working material.
- Original dissertation PDF, academic identifiers and private correspondence.
- Credentials, environment files, local paths and development history.
- Third-party datasets, imagery and assets whose redistribution rights have not been established.

Withheld files remain outside this repository. A public GitHub repository cannot provide private visibility for selected files; those materials must remain local or in a separate private repository. This release does not create or claim a private remote backup.

## Maintenance

The ignore file allows only the five reviewed Markdown documents, three explicitly named research-result images and the ignore file itself. Review every future commit and its history before publishing. Ignore rules do not remove files already committed and can be bypassed by forced additions; they are an additional safeguard, not an access-control mechanism.

No ownership claim over standard research methods or third-party algorithms is implied by keeping this project's implementation private.
